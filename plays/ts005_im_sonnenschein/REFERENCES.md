# Im Sonnenschein: Reference

## Line of Work

Staging Theodor Storm's novella _Im Sonnenschein_ (1854). Eine Inszenierung über die verbotene Liebe von Franziska zu einem französischen Offizier und das Überdauern ihrer Treue.
