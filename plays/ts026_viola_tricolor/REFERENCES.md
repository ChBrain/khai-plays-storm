# Viola tricolor: Reference

## Line of Work

Staging Theodor Storm's novella _Viola tricolor_ (1874). Eine Inszenierung über die Annäherung der jungen Stiefmutter Ines an ihre Familie nach einem schmerzhaften Verlust.
