# Eine Halligfahrt: Reference

## Line of Work

Staging Theodor Storm's novella _Eine Halligfahrt_ (1871). Eine Inszenierung über die Zivilisationsmüdigkeit auf einer einsamen Hallig und die verfehlte Liebe vor der Nordsee.
